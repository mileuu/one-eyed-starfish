# one-eyed starfish · shared board

Website: https://mileuu.github.io/one-eyed-starfish/

- The page lives on the `main` branch (`index.html`).
- All the board content lives in `board.json` on the `data` branch. Every change is a commit, so the full history is there and anything can be restored.
- Viewing is open to anyone with the link. Writing needs the **edit link** (`…/#key=<token>`), which is a fine-grained GitHub token that can only edit this one repo's contents.
- `?local` in the URL turns on a test mode that only saves to your browser.
